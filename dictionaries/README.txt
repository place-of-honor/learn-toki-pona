TOKI PONA DICTIONARY SOURCES
============================

This directory keeps complete snapshots when redistribution terms are clear,
and a source registry for other dictionaries and dictionary-like references.
It is not a claim that no other Toki Pona dictionary exists.

Other dictionary/reference surfaces
-----------------------------------

4. Sonja Lang, Toki Pona Dictionary (ku)
   https://en.wikisource.org/wiki/Toki_Pona_Dictionary
   sona Linku also records public ku translation-frequency data.

5. nimi.li
   https://nimi.li/
   https://nimi.li/about
   Interactive dictionary/aggregator drawing principally on sona Linku,
   lipamanka's semantic dictionary, and public ku material.

6. Lipamanka's Semantic Dictionary
   https://lipamanka.gay/essays/dictionary
   Attribution: lipamanka.
   The author's own text is CC-BY-NC-SA-4.0; the page also contains material
   attributed to other writers, so the whole page is not copied wholesale.

7. lipu Kemeka
   https://kemeka.pona.la/
   English-to-Toki-Pona dictionary with contextual examples.

8. nimi.pona.la
   https://nimi.pona.la/
   Dictionary built around publicly released ku material.

9. Wiktionary
   https://en.wiktionary.org/wiki/Appendix:Toki_Pona
   Toki Pona appendix and dictionary entries under Wikimedia/Wiktionary terms.

10. lipu pi jan Ne / tokipona.net resources
    https://tokipona.net/resources/
    Long-running community reference preserving older dictionary material.

11. jan Pije / older course-era material
    https://lipu-sona.pona.la/
    Historical learning/reference material.

Add another source when a concrete dictionary is found. Copy its full text only
when its redistribution terms are clear.
